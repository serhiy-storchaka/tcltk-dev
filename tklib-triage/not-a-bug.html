    Full verdict

    NOT-A-BUG (user script error). rjust is an attribute without an argument (an alias for anchor east, basic.tcl). The following south is therefore read as a direction, which adds an implicit then waypoint of one movelength (2 cm) to the south. For the first arrow that waypoint lies between from and to, so nothing is visible. The second arrow is only 70 px long, shorter than the 78.8 px step, so it overshoots and comes back. Without south both arrows are correct, even on unfixed trunk.

    • Module diagrams · Bug
    • Tested Tk 9.1, 8.6: canvas coords of both arrows with and without south. With current tcllib, both arrows are also wrong because of the math::geometry orientation bug, see e9c4eeae1f.
    • Cause script semantics; core.tcl Directions treats unknown direction words as then waypoints.
    • Prototype none
    • Suggested ticket action rjust takes no argument. The extra south adds a waypoint one movelength south, which the short second arrow overshoots. Use ... rjust (or anchor east) without south. Close as Works As Designed.
