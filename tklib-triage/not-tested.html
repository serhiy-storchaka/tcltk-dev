Open ticket 1571751fff · Installer · Bug · filed 2006-10-05

Full verdict

CANNOT-TEST (macOS). Probably OUTDATED. installer.tcl:defaults still derives bindir as [file dirname [lindex $tcl_pkgPath end]]/bin. With Apple's system Tcl this gave /System/Library/bin. Apple's system Tcl/Tk is deprecated, and /System has been read-only since macOS 10.15, so installing there is impossible anyway. The path can be set with -app-path.

  • Module installer · Bug
  • Tested code reading only.
  • Cause installer.tcl:defaults (bindir derived from the last tcl_pkgPath entry).
  • Prototype none
  • Suggested ticket action Was reported against tcllib 1.9 with Apple's system Tcl. That Tcl is deprecated and /System is read-only on current macOS, and the binary directory can be given explicitly. Close as Out of Date.
